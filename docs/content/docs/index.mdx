---
title: Introduction
description: Preview markdown in your browser from Neovim and Vim, with live updates, math, diagrams and themes.
---

markdown-preview.nvim opens the markdown buffer you are editing in your browser.
The page updates as you type, before you save, and scrolls along with the
cursor. It renders math, diagrams and GitHub-flavoured markdown, and takes the
look of any shadcn/ui theme.

It works in Neovim and Vim 8.1+, on macOS, Linux, FreeBSD and Windows, and
needs no Node.js: the plugin runs one small server binary, which it downloads
for you.
