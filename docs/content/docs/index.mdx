[markdown-preview.nvim](https://github.com/sammaji/markdown-preview.nvim) opens
the markdown buffer you are editing in your browser. The page updates as you type,
before you save, and scrolls along with the cursor. It renders math, diagrams and
GitHub-flavoured markdown, and takes the look of any shadcn/ui theme.

It works in Neovim and Vim 8.1+, on macOS, Linux, FreeBSD and Windows. The plugin
runs one small server binary, which it downloads for you. Everything is bundled into the
binary, so it runs offline (no CDN).

Fork of [iamcco/markdown-preview.nvim](https://github.com/iamcco/markdown-preview.nvim).
